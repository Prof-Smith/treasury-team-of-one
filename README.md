# Monday-Morning Liquidity Command Center

A deterministic Streamlit demonstration for the TBAFP session, **The Treasury Team of One: Building AI-Powered Financial Solutions**.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The bundled workbook loads automatically. Use the sidebar uploader to substitute a revised workbook with the same required sheet names and row-4 headers.

## Workspaces

1. Monday Morning Inbox
2. Data Review
3. Liquidity Command Center
4. Scenario Laboratory
5. CFO Briefing
6. Model Controls

## Model boundary

Cash calculations are deterministic. The app does not execute payments, move funds, draw facilities, or make approvals. All data are fictional and synthetic.
